افزونهٔ رسمیِ **[HomaCRM](https://homacrm.com)** برای وردپرس و ووکامرس. یک افزونه، یک توکن، همهٔ امکاناتِ هما. نسخهٔ افزونه همیشه برابرِ نسخهٔ زندهٔ هما در لحظهٔ انتشار است.

| | |
|---|---|
| **پیش‌نیاز** | وردپرس ۶٫۰ به بالا · PHP ۷٫۴ به بالا · ووکامرس اختیاری (HPOS پشتیبانی می‌شود) |
| **هزینه** | افزونه رایگان است؛ ۱۵ روز آزمایشیِ رایگانِ هما همراهش است. فقط پیامک‌ها از اعتبارِ پیامکِ پرتالِ شما کم می‌شود. |
| **مجوز** | GPLv2 یا بالاتر · © HomaCRM — فناوران نگین شهر نوین |

## شروع سریع (۳ دقیقه)

1. **نصب:** فایلِ `HomaCRM-<نسخه>.zip` را از [plugin.homacrm.com](https://plugin.homacrm.com/) یا [Releases](https://github.com/Homa-OS/Plugins-HomaCRM/releases/latest) بگیرید و در وردپرس از «افزونه‌ها ← افزودن ← بارگذاری افزونه» نصب و فعال کنید.
2. **توکن:** در منوی **HomaCRM ← Connection** دکمهٔ «ثبت‌نامِ رایگان و دریافتِ توکن» را بزنید (یا اگر حساب دارید: پنلِ هما ← مدیریتِ کاربران ← «توکن‌ها» ← توکنِ اصلی).
3. **اتصال:** توکن را بچسبانید و «ذخیره» را بزنید؛ با «✓ وصل است» و اعتبارِ پیامک تأیید می‌شود. بعد از **Tools & Reports** یک پیامکِ آزمایشی بفرستید.

> ساختنِ توکنِ تازه توکنِ قبلی را باطل می‌کند. توکن را جایی عمومی (کد، گیت، اسکرین‌شات) نگذارید.

### انبار، فاکتور و درگاهِ پرداخت (ووکامرس)

- **قیمت و موجودی از انبارِ هما:** هر ۱۵ دقیقه، و موجودیِ زنده پیش از پرداخت. کالای ووکامرس با متای `_homa_api_id` به کالای هما وصل می‌شود.
- **فاکتور:** سفارش ⇒ فاکتورِ فروش در هما (با اثرِ انبار و سند)؛ پرداخت ⇒ ثبتِ دریافت در خزانه. پرداختِ تکراریِ یک سفارش دوبار ثبت نمی‌شود.
- **درگاهِ پرداختِ هما (`homacrm_pay`):** سفارش پیش از پرداخت فاکتور می‌شود. بازگشت از درگاه تنهایی «پرداخت شد» حساب نمی‌شود؛ افزونه دریافتِ ثبت‌شده روی همان فاکتور را از API می‌خواند و فقط اگر مبلغ کامل رسیده باشد سفارش را پرداخت‌شده می‌کند. حوالهٔ خروج از انبار هم فقط بعد از پرداخت صادر می‌شود.
- توکنِ جدا برای انبار و فاکتور اختیاری است (وقتی انبار در پرتالِ دیگری است).

### پیامک‌های بازاریابی

پیامک‌های تبلیغاتی فقط **۹ صبح تا ۹ شب** فرستاده می‌شوند و متنِ پیش‌فرض عبارتِ لغو (`لغو11`) را دارد. هر کدام جدا روشن/خاموش و قابلِ ویرایش است.

## به‌روزرسانی

هر نسخهٔ تازه با یک Release در همین مخزن منتشر می‌شود (برچسبِ `vX.Y.Z` و فایلِ `HomaCRM-<نسخه>.zip`؛ `homacrm.zip` هم برای به‌روزرسانِ نصب‌های قدیمی می‌ماند). افزونه هر ۱۲ ساعت آن را می‌بیند:

- در «افزونه‌ها» و «به‌روزرسانی‌ها»ی وردپرس دکمهٔ به‌روزرسانی می‌آید و در پیشخوان اعلان با خلاصهٔ تغییرات نشان داده می‌شود.
- برای هر نسخه یک بار به ایمیلِ مدیرِ سایت خبر می‌دهد؛ پیامک به موبایلِ مدیر هم اختیاری است.
- «به‌روزرسانیِ خودکار» نسخهٔ تازه را بی‌کلیک نصب می‌کند.

تغییراتِ هر نسخه: [CHANGELOG.md](CHANGELOG.md).

## حریمِ خصوصی

برای پشتیبانی و دیدنِ نصب‌های بی‌توکن، افزونه هنگامِ **فعال‌شدن، غیرفعال‌شدن، به‌روزرسانی و روزی یک بار** یک خبرِ کوتاه به `https://plugin.homacrm.com/ping` می‌فرستد:

نشانی و نامِ سایت، ایمیلِ مدیرِ سایت، نسخهٔ افزونه/وردپرس/ووکامرس/PHP، زبان، وصل‌بودنِ توکن (فقط بله/خیر، نه خودِ توکن)، کدِ پرتال و یک شناسهٔ تصادفیِ نصب. توکن، مشتری‌ها، سفارش‌ها و محتوای سایت هرگز فرستاده نمی‌شود. همین توضیح در تبِ About هم آمده است.

## برای توسعه‌دهنده

```php
// ارسالِ پیامک از هر جای سایت
do_action( 'homacrm_send_sms', '09121234567', 'سلام!', 'my-plugin' );
// یا
$res = HomaCRM\Sms::send( '09121234567', 'سلام!' ); // ['ok'=>bool,'error'=>string,'data'=>…]

// هر درخواستی به API بیرونیِ هما با توکنِ ذخیره‌شده
$r = HomaCRM\Api::request( 'GET', '/crm/contacts?search=0912' );
```

**هوک‌ها:** `homacrm_sms_message` (فیلترِ متن)، `homacrm_sms_sent`، `homacrm_user_registered`، `homacrm_login_redirect`، `homacrm_form_submitted`.

**REST** (فقط مدیرِ سایت، با Application Password):

```
GET  /wp-json/homacrm/v1/status
POST /wp-json/homacrm/v1/sms   {"mobile":"09…","message":"…"}
POST /wp-json/homacrm/v1/lead  {"firstName":"…","mobile":"09…","notes":"…"}
```

**MCP:** در وردپرس‌هایی که Abilities API دارند (افزونهٔ MCP Adapter وردپرس)، توانایی‌های `homacrm/send-sms`، `homacrm/credit` و `homacrm/create-lead` ثبت می‌شوند. برای دسترسیِ کامل به همهٔ ابزارهای هما (CRM، پیامک، مالی، کارتابل…) از سرورِ MCPِ هما (`homa-mcp-server`) با همین توکن (`HOMA_API_TOKEN`) استفاده کنید.

API کامل: <https://homacrm.com/api/v1/external/docs>

## کوچ از افزونه‌های قدیمی

پس از راه‌اندازی، «پیامکِ حرفه‌ای ووکامرس» (درگاهِ Homais/Negins) و Digits را غیرفعال کنید. کاربرانِ Digits (`digits_phone_no`) و ووکامرس (`billing_phone`) با همان موبایل وارد می‌شوند.

## امنیت

- توکن در گزینهٔ جدا و بدونِ autoload ذخیره می‌شود و هرگز در فرم، لاگ یا خروجی نمایش داده نمی‌شود.
- کدِ ورود فقط به‌صورتِ HMAC و کوتاه‌عمر در transient است؛ ۵ تلاشِ غلط کد را باطل می‌کند.
- هر موبایل هر ۶۰ ثانیه یک کد و حداکثر ۵ کد در ساعت؛ هر IP حداکثر ۱۵ درخواست در ساعت.
- لاگِ پیامک موبایل را پوشانده نشان می‌دهد، متنِ کدِ ورود را ذخیره نمی‌کند و پس از ۳۰ روز پاک می‌شود.
- تأییدِ پرداخت فقط از روی دریافتِ ثبت‌شده در هما است، نه از پارامترهای بازگشت از درگاه.

```
  includes/class-sms.php         ارسال + لاگ
  includes/class-login.php       ورود و ثبت‌نام با پیامک
  includes/class-woocommerce.php پیامکِ سفارش‌ها
  includes/class-shop.php        انبار، قیمت، فاکتور
  includes/class-gateway.php     درگاهِ پرداختِ هما
  includes/class-engage.php      سبد رهاشده، تولد، رهگیری، نظر
  includes/class-crm-sync.php    مخاطبان و معاملات
  includes/class-forms.php       فرم و CF7
  includes/class-abilities.php   REST و MCP
  includes/class-updater.php     به‌روزرسانی از GitHub
  includes/class-telemetry.php   خبرِ نصب
  includes/class-log.php         لاگ

release.sh · set-version.sh      انتشارِ نسخه
```

### انتشارِ نسخهٔ تازه (برای تیمِ هما)

`./set-version.sh` نسخه را از `https://homacrm.com/api/version` می‌خواند و در `homacrm.php` (هر دو جا) و `readme.txt` می‌نویسد؛ `CHANGELOG.md` را بنویسید و `GITHUB_TOKEN=… ./release.sh` را بزنید. لندینگ را با `landing/deploy.sh` منتشر کنید.
